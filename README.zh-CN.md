# Dalamud 插件订阅

使用下面一个自定义插件仓库地址，即可安装当前可用的插件：

```text
https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
```

在 XIVLauncher 中打开 **Dalamud 设置 → 测试版**，添加上面的地址，然后在插件安装器中搜索并安装需要的插件。

当前插件：

- Battlefield Frontline Collector
- PvP Timeline
- Viewport Keeper
- Private Party Markers

本仓库只保存统一订阅索引；各插件源码和发布包仍保存在各自的仓库中。
