# Dalamud Plugins

Use one custom repository URL to install the available plugins:

```text
https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
```

In XIVLauncher, open **Dalamud Settings → Experimental**, add the URL above, then search for the plugin in the Plugin Installer.

Available plugins:

- Battlefield Frontline Collector
- PvP Timeline
- Viewport Keeper
- Private Party Markers

This repository contains only the shared Dalamud subscription index. Plugin source code and release packages remain in their respective repositories.
